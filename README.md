# Ganjdan offline packs

Offline poetry packs for the Ganjdan app (Dadaist Studio): one JSON file per poet, plus `index.json`.
Files are published on [Releases](https://github.com/dadaist-studio/ganjdan-packs/releases).

Poem text comes from the open data of [Ganjoor](https://ganjoor.net) ([ganjoor/ganjoor-data](https://github.com/ganjoor/ganjoor-data)).
Packs hold titles, structure and verse text only: no summaries, commentary, images or audio.

If you hold the rights to a work in these packs and do not want it here, open an issue and it will be removed.
